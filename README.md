# Thirteens 纸牌接龙

纯本地命令行版 **Thirteens** 纸牌接龙：10 堆明牌，移除和为 13 的对子，K 可单独移除；牌库补齐，全清即胜。

## 玩法

- 发 10 堆牌，每堆 1 张明牌；剩余 42 张为牌库。
- 点数：A=1, 2–10=面值, J=11, Q=12, K=13。
- 任意两堆牌之和为 13（如 Q+A、J+2、10+3、9+4、8+5、7+6）可一起移除；K 单独移除。
- 移除后立刻从牌库补牌到空堆；52 张全部移除获胜，无可走步数则失败。

## 运行

需要 Python 3.10+，仅用标准库。

```bash
python -m thirteens        # 交互模式
python -m thirteens --seed 42 --auto   # 自动走子演示（带固定种子）
```

交互指令（堆号为 1–10）：

- `3 8`：移除第 3、8 堆（和为 13）
- `k 5`：单独移除第 5 堆的 K
- `n`：开新局；`q`：退出

## 与经典规则的小创意

- `--auto` 机器人内置贪心策略，可一键演示一整局；
- 每次落子后即时显示"合法走法"数量，方便新手判断局面；
- `--seed` 让每局可复现，适合研究开局胜率。

## 已知限制

- 机器人是贪心策略（先 K 后第一个对子），胜率不高，Thirteens 本身存在无解开局；
- 交互界面为纯文本，无图形动画；
- `--seed` 只控制发牌顺序，不保证可解。
